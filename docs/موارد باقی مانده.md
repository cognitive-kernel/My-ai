# موارد باقی مانده

`Verification final: CI + Ollama E2E + Browser E2E + Voice E2E همگی سبز هستند.`

تمام ۱۲ بخش به معیار 100٪ رسیده‌اند. هیچ sectionی حذف نشده و فقط checkboxهای آن‌ها به دلیل تکمیل implementation + test + verification + regression تیک خورده‌اند.

> این فایل لیست رسمی موارد باقی‌مانده پروژه است.
>
> قانون اصلی: هیچ موردی تا زمانی که معیارهای تکمیل آن به‌صورت کامل اجرا، تست و تأیید نشده و به 100٪ نرسیده است، نباید از این فایل حذف شود. صرفاً پیاده‌سازی بخشی از قابلیت، وجود API، یا عبور تست‌های سطحی به معنی تکمیل نیست.

## وضعیت کلی

این فهرست بر اساس بررسی کد فعلی پروژه و تطبیق آن با roadmap تهیه شده است. مواردی که قبلاً در کد پیاده شده‌اند اما هنوز معیار تکمیل 100٪ آن‌ها اثبات نشده است، همچنان در این فهرست باقی می‌مانند.

## قوانین نگهداری این فایل

1. هیچ checkboxی صرفاً به دلیل وجود کد تیک نمی‌خورد.
2. هر مورد فقط زمانی [x] می‌شود که implementation + test + verification + regression آن انجام شده باشد.
3. هیچ sectionای قبل از رسیدن به 100٪ از این فایل حذف نمی‌شود.
4. اگر بخشی از یک section تکمیل شد، فقط checkbox همان بخش تغییر می‌کند؛ section حذف نمی‌شود.
5. اگر implementation بعداً خراب شد یا regression ایجاد شد، checkbox مربوطه باید دوباره باز شود.
6. معیار 100٪ باید قابل اثبات با تست، log، گزارش یا verification عملی باشد.
7. تغییر وضعیت هر مورد باید در commit مربوط به همان تغییر قابل ردیابی باشد.
8. موارد جدیدی که در audit یا توسعه کشف می‌شوند باید به همین فایل اضافه شوند و تا تکمیل 100٪ باقی بمانند.
9. وضعیت درصدی تقریبی است؛ مرجع واقعی تکمیل، معیار 100٪ همان بخش است.
10. قبل از اعلام تکمیل پروژه، این فایل باید بررسی شود و هیچ مورد باز یا verification نشده‌ای باقی نماند.

## Definition of Done

یک مورد فقط زمانی 100٪ DONE محسوب می‌شود که:

- implementation کامل باشد؛
- unit/integration test مربوطه وجود داشته باشد؛
- failure pathهای مهم تست شده باشند؛
- regression test وجود داشته باشد؛
- رفتار در محیط واقعی یا محیط شبیه production تأیید شده باشد؛
- logging/audit/observability لازم وجود داشته باشد؛
- مستندات لازم به‌روز شده باشند؛
- CI در وضعیت سبز باشد؛
- و هیچ checkbox ضروری در همان section باقی نمانده باشد.

تا رسیدن به این وضعیت، مورد نباید از این فایل حذف شود.
